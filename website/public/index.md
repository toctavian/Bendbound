# Bendbound — Motorcycle route planner and ride recorder

Bendbound is an iPhone app for planning motorcycle routes, recording GPS rides and keeping saved tours. It is currently in early beta.

Official website: https://bendboundapp.com/
Public project: https://github.com/toctavian/Bendbound

## Plan a route

Plan a route with stops, or create a motorcycle round trip by choosing a riding distance and direction. Select fast, winding or twisty roads. Motorway avoidance is available.

## Record and keep rides

Start a recording from the map to keep the GPS trail you actually ride, with distance and riding time. Find recorded rides in My tours and planned routes in Saved.

## GPX support

Import an existing route as a GPX file. Export recorded tracks to take them with you.

## Availability

Bendbound is in early beta for iPhone. Public App Store downloads and TestFlight invitations are not open yet. An Android release is not available. Follow the public GitHub project for development updates. No public download or invitation link is currently published on the website.

## Questions

### Can I download Bendbound?

Not yet. Public App Store downloads and TestFlight invitations are not open. Bendbound is in early beta for iPhone.

### Can I plan a motorcycle round trip?

Yes. Choose a distance and direction, or plan a route with stops. Select fast, winding or twisty roads and optionally avoid motorways.

### Does Bendbound work with GPX?

Yes. Import GPX routes and export recorded tracks.

### Is there an Android version?

There is no public Android release. The app is currently in early beta for iPhone.
