## Platform

web

## Users

Motorcycle riders exploring Bendbound and its route-planning and ride-recording capabilities.

## Product Purpose

A simple, one-page promotional website for the existing Bendbound mobile app.

## Capabilities and Constraints

The app plans standard and round trips, offers fast/winding/twisty preferences,
records GPS rides, saves tours and imports/exports GPX. Present the current app;
never claim that unfinished group location sharing or offline maps are available.
The repository identifies the app as an early iOS beta. A public App Store or
TestFlight URL has not been provided; leave downloads explicitly unavailable.

## Brand Commitments

Use the approved Bendbound logo unchanged and inherit the app's charcoal, red,
white and cyan colour roles. The confirmed public domain is bendboundapp.com.
The user explicitly requests AWS MCP deployment to Lambda. Preserve existing API
DNS and services. This website's hosting is AWS, not Sites hosting.

## Evidence on Hand

The app source, root DESIGN.md, assets/BRANDING.md and native simulator screenshots
from output/design-review. Saved route screenshots contain the app's existing
example tours; describe them as examples. No testimonials or audience counts.
