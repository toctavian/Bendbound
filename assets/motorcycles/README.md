# Motorcycle markers

Original model-inspired illustrations generated with the built-in image generation tool, using actual overhead photographs as shape references. These are not manufacturer photographs, exact model-year replicas, or endorsements. The reference photos are linked below, not bundled in the app.

All PNGs retain genuine alpha transparency, point north and contain the complete motorcycle. `MotorcycleGlyph` renders them at 63 points on the map and 81 points in settings with `contain`. Heading is applied by the enclosing map view; no disc, pin, border, or background is added.

## Generation prompt set

The following summarizes the final prompts and reference roles for regeneration. Mode: built-in image generation, one transparent PNG per motorcycle. Subsequent bikes used the first sprite as a rendering-style reference; the final Honda used the preceding motocross draft as its style reference only.

Shared direction: create a production-ready, detailed realistic top-down motorcycle navigation sprite. Use the supplied overhead photograph for proportions, mentally rotating it so the front points straight up. Strict overhead orthographic view, centered axis, complete wheels visible, minimal transparent padding. Precise mechanical detail and distinct materials, with a silhouette readable at 42 points. No rider, branding, text, circle, badge, pin, platform, white outline, drop shadow or painted background. Genuine transparent PNG alpha.

- Sports: BMW S 1000 RR; red and ivory fairings, sculpted tank, narrow black seat, mirrors, smoked windscreen, titanium exhaust on the right. Use the MotoPlanete overhead photo as the shape reference.
- Adventure: BMW R 1300 GS Adventure; broad satin-silver tank with blue accents, handguards, tall screen, protruding boxer cylinder heads, stepped saddle, luggage rack, aluminium panniers and treaded tires. Use the Paul Tan overhead photo for body proportions and the sports sprite for rendering style.
- Cruiser: Honda Rebel 500; burgundy teardrop tank and fenders, broad low black solo saddle, offset circular speedometer, swept bars with round mirrors, twin rear shocks, right-side black exhaust with silver tip. No ape-hanger bars, windscreen or luggage. Use the webBikeWorld overhead photo for shape and the sports sprite for style.
- Motocross: Honda CRF250R; slender red gripper seat, pointed red front and rear fenders, red/white angular radiator shrouds with restrained blue slivers, silver twin-spar frame, black fuel cap in front of the seat, bare silver bars with red crossbar pad, dark grips and levers, gold forks, serrated pegs, compact right silver exhaust, deeply knobbled tires. No mirrors, road lights, windscreen, road-bike tank or luggage. Racer X reference faces right, so rotate its orientation counterclockwise 90 degrees. Use the preceding motocross sprite only for the realistic rendering style, not its color or body shape.
- Funventure: red 2016 Suzuki V-Strom DL650 ABS, second-generation 2012-2016 proportions. Use the red model photo for body/color, the overhead cockpit photo for tank and controls (recolor blue panels red), and the sports sprite only for rendering style. Candy-red tank shoulders around a broad black center spine, forward silver fuel cap, clear screen, black/red front fairing without the later model's beak, silver upright bars, handguards, stalk mirrors, analog dial plus digital display, long stepped two-person black saddle, red tail panels, open black luggage rack, high right exhaust with silver heat shield. No optional top case or panniers. Strict overhead north-up orientation with complete wheels and minimal transparent padding.
- Scooter: pearl-white Honda PCX125-style scooter, using the PCX overhead reference rotated clockwise 90 degrees so the front faces north. Use the actual teal Deliveroo box photo for the rear box's shape, color, latch and white branding; use the sports sprite only for rendering style. Short dark screen, chrome bars with mirrors, dark textured footboards and central tunnel, long black seat, one proportional teal cuboid box over the rear rack behind the rider seat, lid seam and black latch, white Deliveroo mark and lowercase wordmark on the lid, right silver exhaust. No rider or extra text. The requested box branding is an exception to the shared no-branding constraint, not an affiliation claim.
