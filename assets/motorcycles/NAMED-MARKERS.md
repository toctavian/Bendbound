# Named Motorcycle Markers

Generated with the built-in image generation tool, one transparent bitmap per bike.
These are model-inspired illustrations, not exact factory/model-year replicas.
The reference photos were used for shape only and are not bundled in the app.

- Octav keeps the existing red Suzuki V-Strom DL650 (2016) image and the persisted
  `funventure` ID. Only the displayed name changed.
- Bogdan: green Kawasaki Z650 (2020), `bogdan.png`.
- Radu: red BMW R1200GS, `radu.png`. The displayed year is **2025**, as explicitly
  requested after the earlier 2015 clarification was withdrawn. The artwork uses
  the liquid-cooled R1200GS shape; this label does not assert a factory 2025 model.
- Petre: grey Yamaha Tracer 900 GT (2018), `petre.png`, without bags or cases.
- Foca: grey Triumph Bonneville T100 (2008), `foca.png`.

All use the same north-up orientation and 42-point default/54-point settings sizing
as existing markers, with genuine alpha transparency and no backing circle.
